# Jazzy Mods for Conquest of Elysium 5

Mods for Conquest of Elysium 5 built on [CoE5SE](https://github.com/musical-pianist/coe5se), the script extender. Every mod here needs it.

## Install

Install a mod in three steps, or let the [CoE5SE installer](https://github.com/musical-pianist/coe5se-installer) do them all for you. It installs CoE5SE and every mod here, and updates them all when you run it again. Close the game first.

1. Install [CoE5SE](https://github.com/musical-pianist/coe5se#install).
2. Download the mod's zip from [Releases](https://github.com/musical-pianist/coe5se-mods-suite/releases) and copy its folder into your mods folder: `%APPDATA%\coe5\mods\` on Windows (paste that path into File Explorer's address bar), or `~/.coe5/mods/` on Mac (Finder: Go, Go to Folder).
3. Start the game and turn the mod on in the Mods screen. Its settings, if it has any, are on its page in Mod Settings.

## Mods

Click a mod for its Readme. All these mods need [CoE5SE](https://github.com/musical-pianist/coe5se) to run.

- [Jazzy Game Presets](JazzyGamePresets/README.md): Save your whole new-game setup (map, society, every player slot, every AI's difficulty) as a preset, load it next time, and change the AI and game rules in a game you're already playing.
- [Jazzy Hotkeys](JazzyHotkeys/README.md): Change any key of the game's Keyboard Shortcuts list: 196 actions on 10 screens, picked in Mod Settings.
- [Jazzy Restart](JazzyRestart/README.md): Restart in the Game Menu. It ends the game and starts a new world with the same settings, no relaunch.
- [Jazzy UI Tweaks](JazzyUITweaks/README.md): Delete saves from Load Game, hide the Read Tip button, shrink or hide the mod banners on the menu screens, and see what a ritual needs to cast. You can turn each one back to vanilla in Mod Settings, Jazzy UI Tweaks.
- [Jazzy Cheats](JazzyCheats/README.md): Give yourself resources, drop units anywhere you've seen, get your movement back, and see every plane for a turn. All from the Game Menu.
- [Jazzy AI Observer](JazzyAIObserver/README.md): Watch every AI player at once: what each one did last turn and why, its income, its view of the map, and its battles. Then take over one AI and play its turns.
