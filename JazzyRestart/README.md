Restart in the Game Menu. It ends the game and starts a new world with the same settings, no relaunch.  
**Needs [CoE5SE](../CoE5SE/README.md) from Nexus Mods.**

## What It Adds

### Load Game

In the Game Menu, under Resign. Pick a save and it loads.

### Restart

In the Game Menu (F10 on the map), under Load Game.

- The game ends the way Resign does and generates the new world at once. Both setup screens are skipped.
- Everything you set on Random Map Settings and Setup Participants comes back: map size, society, the players, their classes, AI difficulty, teams and names.
- A class or society set to Random is rolled again.

## Limits

Restart shows in a game started from the main menu on a random map, with one human player. Not in a loaded save, not on a map file, not in network games.

## For Modders

Jazzy Restart is a Lua mod. The script, JazzyRestart.lua, is in the mod's folder to read and learn from.
